## Frågor om git
1. Vad är skillnaden mellan git add och git commit?
Genom git add läggs ändringarna i staging area medan git commit gör en permanent sparfil i git-repot. Fördelen med git add är att man lägger till filer man är intresserad av och eventuellt
ska ha i sin sparfil medan man fortfarande jobbar och ändrar i sin fil. När man är klar med ett stycke eller en del av filen kan man git commit för att ladda upp den till git-repot och på
det viset göra större sparfiler med beskrivningar på vad som har gjorts.
